# Booky live preview

**Paste this in the right-side Browser tab:**

https://salty-wings-lick.loca.lt/booky/preview.html

1. Replace `http://localhost:8080/...` in the browser URL bar with the link above
2. If loca.lt asks to continue, click once
3. Edit `booky/styles.css` on the left → Save → Refresh the browser

To restart preview: **Terminal → Run Task → Booky: Start Preview**
